# Ledger

Moteur de consolidation et de réconciliation de données de P&L.

Il ingère des montants de P&L depuis plusieurs sources aux formats hétérogènes,
les normalise vers un modèle commun, rapproche les montants sur une clé métier
et qualifie les écarts selon des règles explicites de tolérance.
